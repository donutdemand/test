🔑 Discord account tokens

Add as many account tokens as you like — single or bulk. Each one is checked against Discord and shown with its username. Full secrets never leave the server.

How to get an account token: open Discord in your browser → press Ctrl+Shift+I → Application tab → Local Storage → https://discord.com → copy the token value. Never share tokens with anyone — they give full access to the account. ⚠️ Automating user accounts violates Discord's ToS and can get accounts locked or banned; keep intervals generous.

💬 Messaging tasks

Each task sends rotating messages to one channel on a timer, with optional random jitter.

🚪 Server joiner

Paste a server invite link — every active account joins it, one by one with delays. Captchas are solved with your saved key when possible; everything streams into the log below.

🧩 CaptchaAI key

Used when Discord throws a captcha during joins. Stored server-side, shown masked. not set

Without a key, captcha-blocked joins are marked captcha_failed in the log so you can complete them by hand. Solves go to ocr.captchaai.com (in.php/res.php); override with CAPTCHAAI_API_URL if needed. You need active threads on your CaptchaAI account or submits fail with ERROR_ZERO_BALANCE.
